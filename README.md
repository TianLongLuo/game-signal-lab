# GAME · Signal Lab

一个面向成年人的关系事件记录与信号分析 MVP。它帮助用户区分事实与猜测、给互动证据分级、准备低压力回应，并根据真实结果完成复盘。

## 已实现

- 个人目标、表达风格、焦虑触发点与边界设置
- 使用匿名代号的关系档案
- 结构化事件记录：事实、解释、感受、回应与结果
- 透明的本地证据分析：弱 / 中 / 强 / 停止推进
- 替代解释、不确定性说明与边界提醒
- 三个符合用户表达风格的低压力回应选项
- 行动选择与后续结果复盘
- 本地存储、JSON 导出、数据清空
- 18+ 提示、隐私最小化和反操控安全边界

## 产品原则

1. 信号是带不确定性的证据，不是读心答案。
2. 对方的明确表达和真实反馈高于任何推断。
3. 建议要保留用户自己的表达方式，而不是复制“导师话术”。
4. 明确拒绝、不舒服或持续回避时，应停止或降低推进强度。
5. 私密关系数据默认只保存在当前浏览器。

## 运行

项目不依赖构建工具。直接打开 `index.html` 即可使用；也可以在项目目录启动任意静态文件服务器。

例如：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 技术说明

当前版本使用可解释的本地规则引擎，不会把规则分析伪装成 AI。后续可以在保留相同数据结构和安全约束的前提下接入服务端 AI + 知识库：

- 仅向服务端发送用户明确同意的最少字段
- 第三方姓名默认匿名化
- AI 输出继续使用固定“事实 / 替代解释 / 证据等级 / 不确定性 / 回应选项 / 停止条件”结构
- 增加加密存储、账户鉴权、删除与导出接口
