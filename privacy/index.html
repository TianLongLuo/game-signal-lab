隐私保护说明

先把数据去向说清楚。关系日记默认留在你的浏览器；语音、Agent 和匿名分析只有在你明确操作或同意后才会连接相应服务。

更新：2026-08-13 · 测试版

01 / LOCAL

默认留在本机

匿名档案、事件、分析和复盘默认保存在当前浏览器。

02 / CHOICE

主动发送才处理

语音和 Agent 内容不会因登录或打开页面而自动上传。

03 / ISOLATED

账号间隔离

向量知识库按账号隔离，Agent 仅检索当前账号的数据。

04 / CONTROL

随时可撤回

你可以关闭分析、撤回 AI 同意、导出或清空本地记录。

00 / Scope

适用范围

本说明适用于 GAME Signal Lab（rsdgame.online）测试版的网站、账号功能、语音识别、关系思考 Agent 和匿名使用分析。产品仅面向年满 18 岁的成年人。

我们坚持目的明确、最少必要、公开透明和用户可控。由于关系记录可能包含他人的信息，请使用代号，不要输入真实姓名、账号、地址、定位、身份证明或不必要的完整聊天记录。

01 / Data Map

数据如何流动

On device

本地关系日记

匿名档案、事件、结构化分析、复盘和偏好保存在浏览器本地存储中。除非你主动使用需要联网的功能，否则这些正文不离开设备。

Account

账号与权限

服务端处理用户名、密码验证值、会话、会员状态、AI 调用额度、同意状态及必要的安全审计元数据。

Explicit AI

Agent 与故事对话

只有你按下发送的文字才进入模型请求。消息和模型回复会加密存档；匿名档案的最少必要字段进入当前账号的隔离向量知识库。

Voice

语音识别

录音结束后，音频会临时发送给本地自托管 FunASR；不可用时直接提示错误，不向云端外发录音。本站不把音频文件写入关系档案，转写结果先回到输入框，由你确认后再发送。

02 / Details

处理明细

本地数据代号对象档案、互动事件、你的解释与感受、分析结果、复盘、设置。保留到你清空浏览器、本地数据或卸载站点数据。
账号数据用户名、密码验证值、登录会话、会员/授权、50 次初始 AI 调用计数、同意记录和服务审计。用于登录、安全、权限控制与故障排查。
AI 内容你主动发送的消息、模型回复，以及你同意同步的匿名档案最少必要字段。消息存档使用 AES-256-GCM 加密；授权管理员为支持和排障读取时会留下审计记录。
匿名分析只有在你允许后才加载 Google Analytics 4。它会处理页面、语言、功能完成事件、会话统计、粗略地区以及浏览器/设备信息，并可能使用第一方 `_ga` Cookie 区分浏览器；不发送日记正文、档案内容、录音、AI 消息、用户名或站内用户 ID，也不启用 Google Signals 或广告个性化。
技术日志为防滥用、维持会话和定位故障，服务可能处理请求时间、状态码、请求编号及必要的安全元数据。应用审计表不保存本地日记正文、系统提示词、IP 地址或浏览器标识。

请注意：如果你在文本或录音中主动提供可识别个人的信息，它可能随你发起的语音识别或 Agent 请求进入相应服务。请坚持使用代号与最少必要上下文。

03 / Providers

服务提供方

DeepSeek

用于生成故事追问、档案整理和关系思考回复，仅接收你明确发送及本次任务所需的最少上下文。外部模型提供方会按照其服务条款和开发者数据规则处理请求。你可以查阅 DeepSeek 官方隐私政策。

本地 FunASR

自托管 FunASR 是唯一语音识别通道；不可用时返回错误，不把音频发送给云端供应商。音频只用于完成本次转写，不会作为关系档案附件保存。

Google Analytics 4

用于了解访问来源与功能完成率。分析脚本在你同意前不会加载；你可以在「隐私与数据」中随时修改选择。更多信息见 Google Analytics 数据保护说明。

04 / Security

隔离与安全

  • 密码不会以明文保存；会话使用安全 Cookie 与同源请求保护。
  • DeepSeek API 密钥在服务端加密保存，不写入前端代码。
  • 每个账号的向量检索都带用户范围过滤，不允许跨账号检索对象档案。
  • 显式发送的对话存档加密保存；管理员读取与权限修改进入审计记录。
  • 任何系统都不存在绝对安全。请避免在共享设备、公共浏览器或不受控网络中输入敏感信息。

05 / Your Choices

你的选择与权利

管理本地数据

在应用的「隐私与数据」页面中，你可以导出 JSON 备份、导入备份或清空当前浏览器中的全部本地记录。

撤回外部 AI 同意

撤回后，新的 Agent 请求会被拒绝，账号专属知识库会被清空；当前浏览器里的本地日记不受影响。

管理匿名分析

你可以拒绝或重新打开 Google Analytics 偏好。拒绝不会影响记录、档案或 Agent 的核心功能。

提出数据请求

测试期内，如需查询、更正或删除账号侧数据，请通过你获得测试邀请的官方联系渠道联系 GAME Signal Lab 运营者。为避免误删，处理前可能需要验证账号控制权。

06 / Retention

保存期限与变更

本地数据由你控制并留存到你主动清除。账号、配额、加密对话和必要审计数据会在测试账号存续及提供服务、安全排障所需期间保留；撤回 AI 同意会立即停止新的 AI 处理并清除隔离知识库。外部服务的日志与保留期限受各自开发者服务条款约束。

如数据类型、处理目的、外部提供方或用户选择发生重要变化，我们会更新版本和日期，并在需要时重新取得同意。继续使用普通本地记录不代表你自动同意新的外部 AI 处理。
